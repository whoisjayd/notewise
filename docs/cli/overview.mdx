```bash
yt-study [COMMAND] [OPTIONS] [ARGS]
```

Running `yt-study` without any command prints a summary. Running `yt-study COMMAND --help` prints full help for that command.

## Typical workflows

<Tabs>
  <Tab title="First setup">
    <Steps>
      <Step title="Initialize config">
        ```bash
        yt-study setup
        ```
      </Step>
      <Step title="Verify config">
        ```bash
        yt-study config
        yt-study config-path
        ```
      </Step>
      <Step title="First run">
        ```bash
        yt-study process "https://youtube.com/watch?v=VIDEO_ID"
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Daily operations">
    ```bash
    yt-study stats
    yt-study history --limit 25
    yt-study cache --info
    yt-study logs --tail 80
    yt-study doctor
    ```
  </Tab>
  <Tab title="CI / automation">
    ```bash
    yt-study process urls.txt --no-ui
    yt-study process urls.txt --no-ui 2>&1 | tee run.log
    ```
  </Tab>
</Tabs>

## Global behavior

| Behavior | Details |
| --- | --- |
| **Config file** | `~/.yt-study/config.env` loaded automatically. Override directory with `YT_STUDY_HOME`. |
| **Logging** | Structured JSON log written to `~/.yt-study/logs/` for every `process` run. API keys are redacted. |
| **Exit codes** | `0` on success, `1` on any failure. |
