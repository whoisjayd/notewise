Generate comprehensive, structured Markdown study notes from YouTube videos or playlists.

### Synopsis

```bash
notewise process URL [OPTIONS]
```

---

### Arguments

<ParamField path="URL" type="string" required>
  YouTube video URL, playlist URL, bare video/playlist ID, or path to a `.txt` batch file containing one URL per line.
</ParamField>

---

### Options

<ParamField query="--model" type="string">
  **Alias:** `-m`

  LiteLLM model string. Overrides `DEFAULT_MODEL` from config for this run.

  ```bash
  notewise process "URL" --model gpt-4o
  notewise process "URL" -m anthropic/claude-3-5-sonnet-20241022
  ```
</ParamField>

<ParamField query="--output" type="path">
  **Alias:** `-o`

  Output directory path. Overrides `OUTPUT_DIR` from config for this run.

  ```bash
  notewise process "URL" --output ~/my-notes
  ```
</ParamField>

<ParamField query="--format" type="string" default="md">
  Notes output format. Accepted values: `md`, `html`, `pdf`, `docx`.

  `md` keeps the current Markdown-first behavior. `html`, `pdf`, and `docx` render the generated Markdown through the document renderer module with tighter spacing, improved typography, and cleaner DOCX styling.

  You can pass one value or a comma-separated list.

  ```bash
  notewise process "URL" --format html
  notewise process "URL" --format pdf
  notewise process "URL" --format docx
  notewise process "URL" --format md,html,pdf
  ```
</ParamField>

<ParamField query="--language" type="string">
  **Alias:** `-l` · **Repeatable**

  Preferred transcript language code. Repeat the flag to set a fallback chain. Default: `en`.

  ```bash
  notewise process "URL" --language hi       # Hindi first
  notewise process "URL" -l fr -l en         # French, then English
  ```
</ParamField>

<ParamField query="--target-language" type="string" default="English">
  Language for the generated notes themselves. This controls the LLM output language, including headings and structural labels, and is independent from transcript fetch preferences.

  ```bash
  notewise process "URL" --target-language Hindi
  notewise process "URL" --language en --target-language Spanish
  ```
</ParamField>

<ParamField query="--temperature" type="float" default="0.7">
  **Alias:** `-t`

  LLM sampling temperature, range `0.0`–`1.0`. Lower = more deterministic. Higher = more creative.

  ```bash
  notewise process "URL" --temperature 0.3
  ```
</ParamField>

<ParamField query="--max-tokens" type="integer">
  **Alias:** `-k`

  Maximum tokens per LLM response. When not set, the model's own default is used.

  ```bash
  notewise process "URL" --max-tokens 2000
  ```
</ParamField>

<ParamField query="--throttle" type="float" default="0.0">
  Insert a delay between repeated LLM generation calls. Useful when chunked, chapter-based, or quiz generation would otherwise burst too quickly for free-tier or low-quota provider plans.

  `0` disables pacing. The first generation call starts immediately; the delay only applies between later calls.

  ```bash
  notewise process "URL" --throttle 2
  notewise process "URL" --throttle 5
  ```
</ParamField>

<ParamField query="--quiz" type="boolean" default="false">
  Also generate a multiple-choice quiz (`<title>_quiz.md`) alongside the notes. Contains 10–15 questions with answers and explanations.

  ```bash
  notewise process "URL" --quiz
  ```
</ParamField>

<ParamField query="--use-combine-chunk" type="boolean" default="false">
  Use the deprecated legacy chunk-combine flow instead of the default boundary-stitching flow.
  The default stitcher preserves more detail for long videos by reconciling chunk boundaries locally rather than sending all chunk outputs back through one final combine prompt.

  ```bash
  notewise process "URL" --use-combine-chunk
  ```
</ParamField>

<ParamField query="--export-transcript" type="string">
  Export the raw transcript alongside the notes. Accepted values: `txt` (plain text) or `json` (timestamped array).

  ```bash
  notewise process "URL" --export-transcript txt
  notewise process "URL" --export-transcript json
  ```
</ParamField>

<ParamField query="--timestamps" type="boolean" default="false">
  Prefix chapter note headings with deterministic chapter start times for long chapter-aware videos, for example `# [00:34] Intro`.

  This only affects chapter-based output. Standard single-file notes are unchanged.

  ```bash
  notewise process "URL" --timestamps
  ```
</ParamField>

<ParamField query="--force" type="boolean" default="false">
  **Alias:** `-F`

  Re-process videos even if the output directory already exists and the video is in the cache.

  ```bash
  notewise process "URL" --force
  ```
</ParamField>

<ParamField query="--no-ui" type="boolean" default="false">
  Disable the Rich live dashboard. Prints plain progress lines to stdout — suitable for cron jobs, CI pipelines, and log aggregators.

  ```bash
  notewise process "URL" --no-ui
  ```
</ParamField>

<ParamField query="--cookie-file" type="path">
  **Alias:** `--cookies`

  Path to a Netscape-format `.txt` cookies file. Required for private, age-gated, or members-only videos.

  ```bash
  notewise process "URL" --cookie-file ./youtube-cookies.txt
  ```
</ParamField>

### Input types

<Tabs>
  <Tab title="Single video">
    ```bash
    notewise process "https://youtube.com/watch?v=dQw4w9WgXcQ"
    notewise process "https://youtu.be/dQw4w9WgXcQ"
    notewise process "https://youtube.com/shorts/dQw4w9WgXcQ"
    notewise process dQw4w9WgXcQ      # bare 11-character video ID
    ```
  </Tab>
  <Tab title="Playlist">
    ```bash
    notewise process "https://youtube.com/playlist?list=PLxxxxxx"
    notewise process PLxxxxxx          # bare playlist ID
    ```
  </Tab>
  <Tab title="Batch file">
    A plain text file with one URL per line. Blank lines and `#` comment lines are ignored.

    ```bash
    notewise process my-urls.txt
    notewise process ~/course/urls.txt -o ~/course/notes
    ```
  </Tab>
</Tabs>

---

### Output Structure

By default, long transcripts are finalized with chunk **stitching** so adjacent chunk outputs read like one continuous document while preserving detail.
`--use-combine-chunk` keeps the older deprecated combine-all-chunks behavior for compatibility.
`--throttle` paces repeated LLM calls across chunk generation, chapter generation, stitching/combining, and quiz generation.

<Tabs>
  <Tab title="Standard Video">
    <Tree>
      <Tree.Folder name="output" defaultOpen>
        <Tree.File name="Video Title.md" />
        <Tree.File name="Video Title.html" />
        <Tree.File name="Video Title.pdf" />
        <Tree.File name="Video Title.docx" />
        <Tree.File name="Video Title_quiz.md" />
        <Tree.File name="Video Title_transcript.txt" />
        <Tree.File name="Video Title_transcript.json" />
      </Tree.Folder>
    </Tree>

    <Note>Quiz and transcript files are only created with `--quiz` and `--export-transcript` flags.</Note>
  </Tab>
  <Tab title="Long Video with Chapters (> 1 hour)">
    <Tree>
      <Tree.Folder name="output" defaultOpen>
        <Tree.Folder name="Long Course Title" defaultOpen>
          <Tree.File name="01_Introduction.md" />
          <Tree.File name="02_Core Concepts.md" />
          <Tree.File name="03_Advanced Topics.md" />
        </Tree.Folder>
        <Tree.File name="Long Course Title.html" />
        <Tree.File name="Long Course Title.pdf" />
        <Tree.File name="Long Course Title.docx" />
      </Tree.Folder>
    </Tree>

    <Note>
      With `--format md`, long videos keep per-chapter Markdown files. With `--format html`, `pdf`, or `docx`, NoteWise bundles the generated chapter notes into one rendered document. If you request multiple formats like `md,html`, you get both the chapter folder and the bundled rendered file.
    </Note>
  </Tab>
</Tabs>

### Exit codes

| Code | Meaning |
| --- | --- |
| `0` | All videos processed successfully |
| `1` | One or more videos failed, or an unexpected error occurred |

### Examples

```bash
# Basic
notewise process "https://youtube.com/watch?v=VIDEO_ID"

# Custom model and output directory
notewise process "URL" --model gpt-4o --output ~/notes

# Playlist with quiz and transcript export
notewise process "https://youtube.com/playlist?list=PLxxxxxx" \
  --quiz --export-transcript txt

# Deprecated legacy combine mode
notewise process "URL" --use-combine-chunk

# Pace chunked generation for rate-limited plans
notewise process "URL" --throttle 2

# Batch file — non-interactive with high concurrency
MAX_CONCURRENT_VIDEOS=10 notewise process urls.txt --no-ui

# Private video with cookie file
notewise process "URL" --cookie-file ./youtube-cookies.txt

# Re-process with a different model
notewise process "URL" --model claude-3-5-sonnet-20241022 --force

# Long chapter-aware video with timestamped headings
notewise process "URL" --timestamps

# Preferred language fallback chain
notewise process "URL" -l hi -l en
```
