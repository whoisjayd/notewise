```bash
notewise [COMMAND] [OPTIONS] [ARGS]
```

Running `notewise` without any command prints a summary. Running `notewise COMMAND --help` prints full help for that command.

### Typical workflows

<Tabs>
  <Tab title="First setup">
    <Steps>
      <Step title="Initialize config">
        ```bash
        notewise setup
        ```
      </Step>
      <Step title="Verify config">
        ```bash
        notewise config
        notewise config-path
        ```
      </Step>
      <Step title="First run">
        ```bash
        notewise process "https://youtube.com/watch?v=VIDEO_ID"
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="OAuth provider setup">
    ```bash
    notewise auth login chatgpt
    notewise auth login github_copilot
    notewise process "https://youtube.com/watch?v=VIDEO_ID" --model chatgpt/gpt-5.2
    ```
  </Tab>
  <Tab title="Daily operations">
    ```bash
    notewise stats
    notewise history --limit 25
    notewise cache --info
    notewise logs --tail 80
    notewise doctor
    notewise update
    ```
  </Tab>
  <Tab title="CI / automation">
    ```bash
    notewise process urls.txt --no-ui
    notewise process urls.txt --no-ui 2>&1 | tee run.log
    ```
  </Tab>
</Tabs>

### Global behavior

| Behavior | Details |
| --- | --- |
| **Config file** | `~/.notewise/config.env` loaded automatically. Override directory with `NOTEWISE_HOME`. |
| **Logging** | Structured JSON log written to `~/.notewise/logs/` for every `process` run. API keys are redacted. |
| **Exit codes** | `0` on success, `1` on any failure. |
