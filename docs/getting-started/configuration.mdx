## Config file

yt-study reads configuration from:

```text
~/.yt-study/config.env
```

This file is created by `yt-study setup`. It uses a simple `KEY=VALUE` format — no quotes required (they are stripped if present).

Override the config directory:

```bash
export YT_STUDY_HOME=/custom/path
```

## Load order

Settings are resolved in this priority order — later entries win:

<Steps>
  <Step title="Code defaults">Built-in values defined in `_constants.py`.</Step>
  <Step title="config.env">Values written by `yt-study setup` or edited manually.</Step>
  <Step title="Environment variables">Always override the config file.</Step>
  <Step title="CLI flags">Override everything for a single run (e.g. `--model`, `--output`).</Step>
</Steps>

## Essential settings

### Model & API key

Set your default LLM and its matching API key. Only the key for your chosen provider needs to be set.

```bash
# Default — free tier via Google AI Studio
DEFAULT_MODEL=gemini/gemini-2.5-flash
GEMINI_API_KEY=your_key_here
```

Switching providers:

```bash
DEFAULT_MODEL=gpt-4o
OPENAI_API_KEY=sk-...
```

See [LLM Providers](/concepts/providers) for all supported models and key names.

### Output directory

```bash
OUTPUT_DIR=~/study-notes    # default: ./output
```

### Concurrency

```bash
MAX_CONCURRENT_VIDEOS=5     # default: 5 videos processed in parallel
```

### Temperature

```bash
TEMPERATURE=0.7             # default: 0.7 — range 0.0–1.0
```

## Example config.env

```bash
# ~/.yt-study/config.env

DEFAULT_MODEL=gemini/gemini-2.5-flash
OUTPUT_DIR=~/study-notes
MAX_CONCURRENT_VIDEOS=3
TEMPERATURE=0.7
# MAX_TOKENS=2000

GEMINI_API_KEY=your_key_here
# OPENAI_API_KEY=sk-...
# ANTHROPIC_API_KEY=sk-ant-...
```

## Config commands

| Command | What it does |
| --- | --- |
| `yt-study config` | Show resolved config (API keys masked) |
| `yt-study config-path` | Print path to the active config file |
| `yt-study edit-config` | Open `config.env` in `$EDITOR` |
| `yt-study setup --force` | Re-run the interactive wizard |

<Tip>
  After any config change, run `yt-study config` to confirm the resolved values before your next run.
</Tip>
