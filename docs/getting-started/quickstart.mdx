<Info>
  This guide is optimized for first-time setup. You only need to run `setup` once — all subsequent runs use the saved config.
</Info>

<Steps>
  <Step title="Install yt-study">
    ```bash
    uv tool install yt-study
    ```

    Need pip or Docker instead? See [Installation](/getting-started/installation).
  </Step>

  <Step title="Get an API key">
    The default model is **Gemini 2.5 Flash** — free tier, no billing required.

    1. Visit [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
    2. Create a new API key
    3. Copy it for the next step

    <Note>
      Any supported provider works. See [LLM Providers](/concepts/providers) for OpenAI, Anthropic, Groq, and more.
    </Note>
  </Step>

  <Step title="Run the setup wizard">
    ```bash
    yt-study setup
    ```

    The interactive wizard prompts for your provider and API key, then writes `~/.yt-study/config.env`. Run this once.
  </Step>

  <Step title="Process a video">
    ```bash
    yt-study process "https://youtube.com/watch?v=VIDEO_ID"
    ```

    A live progress dashboard shows while yt-study fetches the transcript and generates notes. When finished, open `./output/` to find your Markdown study notes.
  </Step>
</Steps>
