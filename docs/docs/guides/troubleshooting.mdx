### Quick triage

Run these three commands first — they cover 90% of issues:

```bash
notewise doctor
notewise config
notewise logs --tail 80
```

---

### Common failure modes

<AccordionGroup>
  <Accordion title="Missing or wrong API key">
    **Symptoms:** Process fails early with provider authentication errors. `doctor` reports a missing key.

    **Fix:**
    ```bash
    notewise config
    notewise setup --force
    ```

    Key → model mapping:
    | Model prefix | Required key |
    | --- | --- |
    | `gpt-*` | `OPENAI_API_KEY` |
    | `claude-*` | `ANTHROPIC_API_KEY` |
    | `gemini/*` | `GEMINI_API_KEY` |
    | `groq/` | `GROQ_API_KEY` |
  </Accordion>

  <Accordion title="No transcript available">
    **Symptoms:** Video fails with transcript-unavailable messages.

    **Fix:**
    ```bash
    notewise info "URL"                 # see available transcript languages
    notewise process "URL" -l en
    notewise process "URL" -l hi -l en  # fallback chain
    ```

    If captions are disabled by the creator, use another video.
  </Accordion>

  <Accordion title="Private, age-restricted, or members-only video">
    **Symptoms:** Errors mention sign-in, private content, or age restrictions.

    **Fix:**
    ```bash
    notewise process "URL" --cookie-file ./youtube-cookies.txt
    ```

    See [Private Videos](/docs/guides/private-videos) for cookie export instructions.
  </Accordion>

  <Accordion title="YouTube rate limiting or temporary block">
    **Symptoms:** Errors mention rate limiting, unusual traffic, or temporary blocks.

    **Fix:** Lower concurrency and retry later:
    ```bash
    # ~/.notewise/config.env
    MAX_CONCURRENT_VIDEOS=2
    YOUTUBE_REQUESTS_PER_MINUTE=5
    ```
  </Accordion>

  <Accordion title="Output write permission denied">
    **Symptoms:** Process fails near completion with file write errors.

    **Fix:**
    ```bash
    notewise process "URL" --output ./output
    ```

    Ensure the target directory is writable by your user.
  </Accordion>

  <Accordion title="Model too slow or expensive">
    **Symptoms:** High cost or long generation times in `notewise stats`.

    **Fix:** Switch to a faster/cheaper model:
    ```bash
    notewise process "URL" --model gemini/gemini-2.5-flash
    ```
  </Accordion>
</AccordionGroup>

### Debug workflow for a failing URL

<Steps>
  <Step title="Inspect the source">
    ```bash
    notewise info "URL"
    ```
  </Step>
  <Step title="Re-run in plain output mode">
    ```bash
    notewise process "URL" --no-ui
    ```
  </Step>
  <Step title="Read the latest logs">
    ```bash
    notewise logs --tail 120
    ```
  </Step>
  <Step title="Force a clean re-run if needed">
    ```bash
    notewise process "URL" --force
    ```
  </Step>
</Steps>

### Cache issues

Only clear the cache when local metadata appears stale or corrupted:

```bash
notewise cache --info
notewise cache --clear --yes
```

For routine cleanup, prefer pruning:

```bash
notewise cache --prune 30
```
