### Config file

notewise reads configuration from:

```text
~/.notewise/config.env
```

This file is created by `notewise setup`. It uses a simple `KEY=VALUE` format — no quotes required (they are stripped if present).

Override the config directory:

```bash
export NOTEWISE_HOME=/custom/path
```

---

### Load order

Settings are resolved in this priority order — later entries win:

<Steps>
  <Step title="Code defaults">Built-in values defined in `_constants.py`.</Step>
  <Step title="config.env">Values written by `notewise setup` or edited manually.</Step>
  <Step title="Environment variables">Always override the config file.</Step>
  <Step title="CLI flags">Override everything for a single run (e.g. `--model`, `--output`).</Step>
</Steps>

### Essential settings

### Model & API key

Set your default LLM and its matching API key. Only the key for your chosen provider needs to be set.

```bash
# Default — free tier via Google AI Studio
DEFAULT_MODEL=gemini/gemini-2.5-flash
GEMINI_API_KEY=your_key_here
```

Switching providers:

```bash
DEFAULT_MODEL=gpt-5.5
OPENAI_API_KEY=sk-...
```

Gateway and hosted providers use their LiteLLM prefix and matching key:

```bash
DEFAULT_MODEL=openrouter/openai/gpt-5
OPENROUTER_API_KEY=sk-or-...
```

OAuth/device-flow providers such as ChatGPT subscription and GitHub Copilot do not use a static API key. Log in once from an interactive terminal, then select a `chatgpt/*` or `github_copilot/*` model:

```bash
notewise auth login chatgpt
notewise auth login github_copilot

DEFAULT_MODEL=chatgpt/gpt-5.2
# or
DEFAULT_MODEL=github_copilot/gpt-5-mini
```

Tokens default to `~/.notewise/oauth/chatgpt` and `~/.notewise/oauth/github_copilot` so they stay inside the notewise state directory unless you override the paths.

See [LLM Providers](/docs/how-it-works/providers) for all supported models and key names.

### Output directory

```bash
OUTPUT_DIR=~/study-notes    # default: ./output
```

### Concurrency

```bash
MAX_CONCURRENT_VIDEOS=5     # default: 5 videos processed in parallel
```

### Temperature

```bash
TEMPERATURE=0.7             # default: 0.7 — range 0.0–1.0
```

### Example config.env

```bash
# ~/.notewise/config.env

DEFAULT_MODEL=gemini/gemini-2.5-flash
OUTPUT_DIR=~/study-notes
MAX_CONCURRENT_VIDEOS=3
TEMPERATURE=0.7
# MAX_TOKENS=2000

GEMINI_API_KEY=your_key_here
# OPENAI_API_KEY=sk-...
# ANTHROPIC_API_KEY=sk-ant-...
# OPENROUTER_API_KEY=sk-or-...
# CHATGPT_TOKEN_DIR=~/.notewise/oauth/chatgpt
# GITHUB_COPILOT_TOKEN_DIR=~/.notewise/oauth/github_copilot
```

### Config commands

| Command | What it does |
| --- | --- |
| `notewise config` | Show resolved config (API keys masked) |
| `notewise config-path` | Print path to the active config file |
| `notewise edit-config` | Open `config.env` in `$EDITOR` |
| `notewise auth login <provider>` | Run OAuth/device-flow login for ChatGPT or GitHub Copilot |
| `notewise setup --force` | Re-run the interactive wizard |

<Tip>
  After any config change, run `notewise config` to confirm the resolved values before your next run.
</Tip>
