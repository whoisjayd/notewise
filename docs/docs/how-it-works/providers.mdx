notewise supports a wide range of LLM providers via [LiteLLM](https://github.com/BerriAI/litellm). You can use any model LiteLLM supports by setting the `--model` flag or the `DEFAULT_MODEL` config key.

---

### Model string format

```terminal
provider/model-name
```

```bash
gemini/gemini-2.5-flash
gpt-5.5
claude-sonnet-4-5-20250929
groq/llama-3.3-70b-versatile
openrouter/openai/gpt-5
github_copilot/gpt-5-mini
chatgpt/gpt-5.2
```

Some models can be specified without a provider prefix when the name is unambiguous:

```bash
gpt-5.5                         # routes to OpenAI
claude-sonnet-4-5-20250929      # routes to Anthropic
```

### Provider routing

If the model string contains `/`, the prefix before the slash is the provider. Otherwise, heuristics based on model name prefixes are used.

| Model Prefix | Provider | Required Env Var |
| --- | --- | --- |
| `gemini/*` | Google Gemini | `GEMINI_API_KEY` |
| `vertex/*`, `vertex_ai/*` | Google Vertex | `GEMINI_API_KEY` |
| `openai/*`, `gpt*`, `o1*`, `o3*`, `o4*` | OpenAI | `OPENAI_API_KEY` |
| `anthropic/*`, `claude*` | Anthropic | `ANTHROPIC_API_KEY` |
| `groq/*` | Groq | `GROQ_API_KEY` |
| `xai/*`, `grok*` | xAI | `XAI_API_KEY` |
| `mistral/*` | Mistral | `MISTRAL_API_KEY` |
| `cohere/*`, `command*` | Cohere | `COHERE_API_KEY` |
| `deepseek/*` | DeepSeek | `DEEPSEEK_API_KEY` |
| `openrouter/*` | OpenRouter | `OPENROUTER_API_KEY` |
| `azure/*`, `azure_ai/*`, `azure_text/*` | Azure | `AZURE_API_KEY` or `AZURE_OPENAI_API_KEY` |
| `vercel_ai_gateway/*` | Vercel AI Gateway | `VERCEL_AI_GATEWAY_API_KEY` |
| `together_ai/*`, `together/*` | Together AI | `TOGETHERAI_API_KEY` |
| `fireworks_ai/*` | Fireworks AI | `FIREWORKS_AI_API_KEY` |
| `perplexity/*` | Perplexity | `PERPLEXITYAI_API_KEY` |
| `huggingface/*`, `replicate/*`, `cerebras/*`, `deepinfra/*`, `sambanova/*`, `cloudflare/*` | Major hosted providers | Matching provider API key |
| `chatgpt/*`, `github_copilot/*` | OAuth providers | Device flow; no static API key |
| `bedrock/*`, `bedrock_converse/*`, `amazon_nova/*` | AWS providers | AWS SDK credential chain |

If the resolved provider needs a static API key and that key is missing, the CLI shows the missing config name before any video processing starts. OAuth and ambient-credential providers skip static API-key checks and rely on their provider-specific login or SDK credential chain.

<Tip>
  ChatGPT subscription models use LiteLLM's Responses API. GitHub Copilot Codex models also use Responses API; regular Copilot chat models such as `github_copilot/gpt-5-mini` use Chat Completions.
</Tip>

<Warning>
  OAuth providers need an interactive login before non-interactive runs. Use `notewise auth login chatgpt` or `notewise auth login github_copilot`; LiteLLM prints a device code or browser URL, then notewise defaults token storage to `~/.notewise/oauth/chatgpt` or `~/.notewise/oauth/github_copilot` for reuse.
</Warning>

### OAuth providers

ChatGPT subscription and GitHub Copilot are not configured with API keys in `config.env`.

```bash
notewise auth login chatgpt
notewise auth login github_copilot
```

Codex subscription users should run `notewise auth login chatgpt`; `codex` remains a compatibility alias for ChatGPT subscription login.

After login, use the provider model normally:

```bash
notewise process "URL" --model chatgpt/gpt-5.2
notewise process "URL" --model github_copilot/gpt-5-mini
```

Token storage defaults:

| Provider | Default token directory | Override |
| --- | --- | --- |
| ChatGPT Subscription | `~/.notewise/oauth/chatgpt` | `CHATGPT_TOKEN_DIR` |
| GitHub Copilot | `~/.notewise/oauth/github_copilot` | `GITHUB_COPILOT_TOKEN_DIR` |

<Note>
  The setup wizard uses the bundled LiteLLM text-model snapshot and filters out unsupported non-text models. If a model disappears or a provider rejects access, regenerate the snapshot and update provider examples together.
</Note>

### Quickstart: Changing the default model

Edit `~/.notewise/config.env`:

```bash
DEFAULT_MODEL=gpt-5.5
OPENAI_API_KEY=sk-...
```

Or override for a single run:

```bash
notewise process "URL" --model gpt-5.5
```

### Usage tracking

After each video, notewise records token usage and estimated cost in SQLite.

```bash
notewise stats                                       # all-time totals
notewise stats --model gemini/gemini-2.5-flash       # filter by model
notewise stats --since 7d                            # last 7 days
```

Cost estimates come from LiteLLM's `completion_cost()` and are approximate.
