<Info>
  Treat pipeline events as the canonical progress interface for dashboard and custom UI integrations. Do not derive progress from log text.
</Info>

notewise emits typed events from the processing pipeline. The Rich dashboard and plain `--no-ui` output modes both subscribe to this stream.

---

### Event Object

Each event contains:

| Field | Description |
| --- | --- |
| `event_type` | The event identifier (e.g., VIDEO_SUCCESS, TRANSCRIPT_FETCHED) |
| `video_id` | YouTube video ID |
| `title` | Video title |
| `chapter_number` | Current chapter index (for chapter-aware videos) |
| `total_chapters` | Total chapters in video |
| `chunk_number` | Current chunk index during generation |
| `total_chunks` | Total chunks to process |
| `error` | Error message if the event represents a failure |
| `output_path` | Path to generated output file |

---

### Event Types

<Steps>
  <Step title="Pipeline">
    | Event | Description |
    | --- | --- |
    | `PIPELINE_START` | Pipeline run started |
    | `PIPELINE_COMPLETE` | Pipeline run finished |
  </Step>
  <Step title="Metadata">
    | Event | Description |
    | --- | --- |
    | `METADATA_START` | Metadata fetch started |
    | `METADATA_FETCHED` | Metadata fetched successfully |
  </Step>
  <Step title="Transcript">
    | Event | Description |
    | --- | --- |
    | `TRANSCRIPT_FETCHING` | Transcript retrieval started |
    | `TRANSCRIPT_FETCHED` | Transcript retrieval complete |
  </Step>
  <Step title="Generation">
    | Event | Description |
    | --- | --- |
    | `GENERATION_START` | Flat generation started |
    | `CHUNK_GENERATING` | Transcript chunk generation in progress |
    | `GENERATION_COMBINING` | Multi-chunk combine stage |
    | `GENERATION_COMPLETE` | Main notes generation complete |
  </Step>
  <Step title="Chapter">
    | Event | Description |
    | --- | --- |
    | `CHAPTER_GENERATING` | Chapter generation started |
    | `CHAPTER_CHUNK_GENERATING` | Chapter chunk generation progress |
    | `CHAPTER_COMBINING` | Chapter combine stage |
    | `CHAPTER_COMPLETE` | Chapter generation complete |
  </Step>
  <Step title="Quiz">
    | Event | Description |
    | --- | --- |
    | `QUIZ_GENERATING` | Quiz generation started |
    | `QUIZ_CHUNK_GENERATING` | Quiz chunk generation progress |
    | `QUIZ_COMBINING` | Quiz combine stage |
    | `QUIZ_COMPLETE` | Quiz generation complete |
  </Step>
  <Step title="Final">
    | Event | Description |
    | --- | --- |
    | `VIDEO_SUCCESS` | Video completed successfully |
    | `VIDEO_SKIPPED` | Video skipped due to cache/output checks |
    | `VIDEO_FAILED` | Video failed with error context |
  </Step>
</Steps>

### Typical event sequences

<Tabs>
  <Tab title="Standard video">
    ```text
    PIPELINE_START
    METADATA_START → METADATA_FETCHED
    TRANSCRIPT_FETCHING → TRANSCRIPT_FETCHED
    GENERATION_START
    CHUNK_GENERATING × n
    GENERATION_COMBINING  (only if multi-chunk)
    GENERATION_COMPLETE
    VIDEO_SUCCESS
    PIPELINE_COMPLETE
    ```
  </Tab>
  <Tab title="Chapter-aware video">
    ```text
    PIPELINE_START
    METADATA_START → METADATA_FETCHED
    TRANSCRIPT_FETCHING → TRANSCRIPT_FETCHED
    ┌─ CHAPTER_GENERATING
    │  CHAPTER_CHUNK_GENERATING × n
    │  CHAPTER_COMBINING
    └─ CHAPTER_COMPLETE
    (repeated per chapter, concurrent)
    GENERATION_COMPLETE
    VIDEO_SUCCESS
    PIPELINE_COMPLETE
    ```
  </Tab>
  <Tab title="Skipped video">
    ```text
    PIPELINE_START
    METADATA_START → METADATA_FETCHED
    VIDEO_SKIPPED
    PIPELINE_COMPLETE
    ```
  </Tab>
</Tabs>

---

### Integration

- Use events as the source of truth for progress UI
- For custom frontends, subscribe through the pipeline `on_event` callback and render by `event_type`
- Avoid deriving progress solely from log text — the event stream is the stable API
