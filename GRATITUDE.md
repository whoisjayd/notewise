# Open Source Gratitude

yt-study exists because of open-source software and the people who maintain it.

This file acknowledges the major libraries and tools used directly in this project. It may not list every transitive dependency, but each one is appreciated.

## Core Runtime Dependencies

- [LiteLLM](https://github.com/BerriAI/litellm) - unified LLM provider interface
- [Typer](https://github.com/tiangolo/typer) - CLI framework
- [Rich](https://github.com/Textualize/rich) - terminal UI and formatting
- [aiolimiter](https://github.com/mjpieters/aiolimiter) - async rate limiting
- [SQLAlchemy](https://github.com/sqlalchemy/sqlalchemy) - database ORM and persistence
- [Pydantic](https://github.com/pydantic/pydantic) - validation and typed models
- [pydantic-settings](https://github.com/pydantic/pydantic-settings) - settings and environment config
- [structlog](https://github.com/hynek/structlog) - structured logging

## Build, Packaging, and Quality Tooling

- [uv](https://github.com/astral-sh/uv) - dependency and environment management
- [Hatchling](https://github.com/pypa/hatch) - package build backend
- [Ruff](https://github.com/astral-sh/ruff) - linting and formatting
- [ty](https://github.com/astral-sh/ty) - static type checking
- [pre-commit](https://github.com/pre-commit/pre-commit) - local quality automation
- [Bandit](https://github.com/PyCQA/bandit) - security checks
- [Deptry](https://github.com/fpgmaas/deptry) - dependency hygiene checks

## Testing Stack

- [pytest](https://github.com/pytest-dev/pytest) - test framework
- [pytest-asyncio](https://github.com/pytest-dev/pytest-asyncio) - async test support
- [pytest-cov](https://github.com/pytest-dev/pytest-cov) - coverage reporting
- [pytest-mock](https://github.com/pytest-dev/pytest-mock) - mocking helpers
- [pytest-xdist](https://github.com/pytest-dev/pytest-xdist) - parallel test execution

## Thank You

To all maintainers, reviewers, and contributors in the open-source ecosystem: thank you for your work.

If you maintain one of these projects and would like your name, organization, or preferred project link represented differently, please open an issue or pull request.
